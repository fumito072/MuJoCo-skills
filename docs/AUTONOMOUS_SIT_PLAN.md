# G1 自律「障害物回避 → 椅子に着座」マスタープラン

**ステータス: v3 — 実在の椅子(FBX取込「3階講堂遠隔操作席」)へ台上から着座、ランダム化30/30成功 — 2026-06-11**

## 0. v3: 実在の椅子(g1-isu 連携)— 台上スタート着座 達成

実機環境の椅子(FBX→153凸包、`assets/real_chair/`、g1-isu プロジェクト由来)に対し、
フットレスト台(0.22m)上から着座する `training/g1_real_chair_sit.py` が
**ランダム化スポーン(±5cm/±8°)30/30 = 100%** で成功。
着座状態: base z 0.800 / 骨盤 pitch +0.1° / 胴体リーン 6.3° / 椅子支持 120-260N。
動画: `assets/g1_real_chair_sit.gif`

**v3 で物理が教えた決定的事実(全て実測)**:
1. **この椅子には床から座れない**: 座面 0.635m > 直立時の骨盤底面 0.600m。
   台に乗ることがこの椅子の使用前提(段差0.22m登り = Phase 3 未解決スキル)
2. **0.6×0.3m の台の上では歩行ポリシーは使えない**: コールドスタートの初期ステップで
   台から歩き落ちる(スイープで大量観測)。さらに歩行中の脚は決して静止しない
   (両足接地瞬間でも関節速度 ≥0.6 rad/s)ため、歩行からの開ループ降下は
   クッション前縁の曲面で必ず横転した
3. **解 = SITモード剛性ゲイン(kp300/kd8)+静的降下**: 実機のモード別PD切替と同じ機構
   (g1-isu の pretrained_walker も kp500 で同様)。剛性立位は安定(軟ゲインの
   「2秒時限爆弾」が消滅)、剛性降下は基準軌道を強制して**クッションの奥へ20cm
   滑り込み、どこから始めても同一の着座姿勢に自己収束**(セルフファネリング)。
   到着誤差<降下バスンなので台上での位置補正自体が不要
4. 腰補正は骨盤がフラットに着くため −0.10 で十分(パーチ前提の −0.25 は過剰)

**Phase 2 成果物(g1-isu RL への供給)**:
- `training/real_chair_calibration.json` — 着座目標の実測値(彼らの reward 目標
  seat+0.10m は実測 z0.800/y+0.085 とズレ)、降下レシピ、バスン、報酬シェーピング指針
- `demos/real_chair_sit/demo_*.npz` — 成功軌道30本(50Hz, qpos/qvel/ctrl、
  状態レベル=ゲイン非依存。BC/DeepMimic 流の模倣・relabel 用)

**残トラック**: 段差0.22m登り(Phase 3、g1-isu の RL が床スポーンで未習得の部分)、
床→台→着座のフルチェーン統合、椅子位置の知覚化。

## 2. 椅子と衝突モデル(v2 の核心)

**椅子**(`g1_sit_env.add_real_chair_geoms`): 座面板(0.42×0.40 m)+ 背もたれ(高さ0.39→0.79 m)
+ 4脚。**ロボットの腿・脛・足はモデル付属の衝突ジオメトリ(contype=0)を明示 `<pair>` で椅子と
接続** — 歩行や自己衝突に一切影響しない外科的追加で、脚はもう椅子を貫通できない。
胴体は背もたれ用のプロキシボックスを追加(後傾を背もたれが受け止める)。

**実測に基づく2つの校正(ここが本質)**:

1. **骨盤ボックスの実機校正**: 旧ボックス底面(ベース−0.105 m)は**実機メッシュより5 cm 浅かった**
   (pelvis メッシュ bbox 底面の実測 = ベース−0.155 m。股関節モーターは股関節軸より下に張り出す)。
   浅いままだと腿が座面に載った時に「尻」が座面に届かず、前傾34°のパーチ姿勢で止まる。
   → `PELVIS_COL_SIZE/POS` をメッシュに一致するよう修正(底面 −0.155)。

2. **座面高はロボットの体格で決まる**: 完全着座姿勢の骨盤底面は z≈0.391 → **身長1.32 m の G1 が
   直立で深く座れる座面高は 0.39 m**。0.45 m の人間用椅子は G1 には高いスツールで、物理は正直に
   「前傾パーチ」を返す(実測 +34°)。人間用椅子への着座(尻を支点に座面を滑って奥へ・パーチ
   バランス)は別スキル = RL トラック。

**着座バスン(0.39 m 現実椅子・実測)**: 前方 +8 / 後方 −5 / 横 ±8 cm、ヨー ±20°
(35°に非単調な転倒穴 → ハード上限 ±25°)。

## 3. アーキテクチャ: 1モデル + FSM(50 Hz)

学習済みモデルは**歩行1個だけ**(公式29DOF joystick ONNX)。

```
NAVIGATE ──dist<0.7m──▶ TURN ──|yaw_err|<20°──▶ ALIGN(後ろ向き歩行+ヨーサーボ)
   ▲                                               │ err<4.5cm & |yaw_err|<15° (0.5s)
 VFH 21レイ                                        ▼
 (group 4)              リトライ(≤5回)◀──── SETTLE(ステーションキーピング足踏み)
                            ▲                      │ 両足接地 ∧ 足左右揃い ∧ 非対称速度
                            └──予算外/タイムアウト  │ ゲート ∧ 低ジャイロ/ロール ∧ 予算内
                                                   ▼
                                            SIT(0.7s 直接降下)──▶ HOLD(3s)
```

設計上の決定打(全て実測から導出):

- **立位を経由しない直接降下**: 開ループのキーフレーム立位は**約2秒で前方転倒する時限爆弾**
  (足首kp=20、ポリシーの能動バランスなしでは立てない — dx=0・椅子なしで実測 pitch +78°/3s)。
  しかもカット時の残留速度を殺せない(0.1 m/s の滑空 = 10 cm のミス)。カット→即降下で
  無制御時間を~0.55秒に圧縮し、残りの運動量は**座面自体が殺す**。
- **非対称速度ゲート**: 体座標 vx の「椅子から遠ざかる向き」は +0.03 m/s までしか許さない
  (滑空して座面の手前の空中に着座する =実測した失敗)。「椅子へ向かう向き」は −0.08 まで許容
  (倒れても座面が受け止める安全方向)。
- **足踏みの両脚支持期は1〜3ティック(0.02-0.06 s)しかない**(実測)— 「静かな両脚支持期を
  待つ」ゲートは構造的に成立しない。着地瞬間でカットし、足左右揃い(|x_L−x_R|<0.10 m)で
  歩幅中カットを幾何的に排除。
- **SETTLE はステーションキーピング**(トリム+微小位置サーボ): 開ループトリムは進行方向・
  履歴依存で、後ろ向き歩行後は3 cm/s で椅子側に漂流した(実測)→ 閉ループで張り付く。
- **ドック点 = 座面前縁 + 4 cm**: 立位の脛上端(z 0.405)と座面(上端 0.39)のマージン、
  かかとと前脚のクリアランス、着座バスンの中心を同時に満たす実測位置。

## 4. E2E でのみ露出した失敗モードの記録(v1+v2 全11回)

統合は部品の和ではない。すべて E2E でのみ顕在化した:

| # | 失敗 | 根本原因 | 対策 |
|---|---|---|---|
| 1 | ドッキング2.5cmでも転倒 | ヨー無制御(+64°) | ヨーサーボ+全ゲートにヨー条件 |
| 2 | 降下0.4sでロール暴走・横転 | 足踏み非対称相からの直接降下 | 着地瞬間ゲート(後にv2で再設計) |
| 3 | 安定判定が振動の山に当たる | 固定時間判定 | ポーリング化(後に撤廃) |
| 4 | 椅子の縁に尻もち・スタック | タイムアウト時に予算外でもカット | 予算+静穏の同時必須化 |
| 5 | SETTLE中に椅子へ3cm/s漂流 | トリムの進行方向・履歴依存性 | ステーションキーピング化 |
| 6 | 着地瞬間カットで立位が座屈 | 荷重移行未完(ジャイロ−1.65) | ストリーク化(→構造的に不成立と判明) |
| 7 | 静穏ストリークが永遠に来ない | 両脚支持期が1-3ティックしかない | 「待つ」の放棄、試行+検証+リトライ |
| 8 | 立位検証合格→降下で転倒 | 開ループ立位=2秒の時限爆弾 | 検証窓を1秒に圧縮(→不十分) |
| 9 | 降下中 pitch+38° | 振動極値(角速度0)でカット | ジャイロ条件(→極値はすり抜ける) |
| 10 | 座面の手前の空中に着座 | カット速度+0.12が1秒滑空=13cmミス | **立位廃止・直接降下+非対称速度ゲート** |
| 11 | (v2初期)立位で腿が座面貫通 | 人間椅子はG1に高すぎ+ボックス5cm浅い | 実機校正+体格適合椅子(§2) |

## 6. 今後のトラック(優先度順)

### A. 残った正直な注記の解消
- **障害物×脚の衝突ペア未接続**(回避は VFH+骨盤ボックスで強制、脚はまだ障害物を貫通可能)。
  接続すると最小クリアランス0.11mでは脚が掠るため、VFH の SAFE マージン再調整とセット
- 配置ランダム化 N=50 成功率スイープ(椅子位置・障害物・初期姿勢)

### B. 堅牢化(RL トラック)
- RL 着座ポリシー: 進入状態ランダム化(xy/ヨー/速度)+椅子ランダム化(高さ 0.35-0.50 = 
  人間椅子パーチ含む)。先行研究: 2段階 sit(座面高+0.13m目標)、InterPhys。
  学習は Mac CPU-PPO(20Mステップ≈15-30分)or クラウドGPU、推論は常にローカル
- 人間用 0.45 m 椅子への着座(座面を奥へ滑る・パーチ)= 専用スキル

### C. 知覚の自律化
- VFH の特権情報(geom group)→ 深度カメラ擬似 LiDAR(`vision_nav.py` で実証済み、移植)
- 椅子位置・向きの検出(現在は既知座標)

### D. VLA 統合
- 音声→Whisper→NLU(Qwen/MLX)→FSM 発行のパイプラインは構築済み(voice_chair.py)。
  実行器を本 E2E に差し替えれば「声で言うと避けて座る」が1物理で繋がる
- FSM をデモ生成エンジンにして模倣学習→単一ポリシー蒸留(train-once / infer-local)
